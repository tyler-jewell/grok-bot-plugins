SkiHerd

Live group map for a ski day

See your group on one map.

Create a group, invite up to nine friends, and share live positions for the rest of the day. This is a free plugin anyone can use from Grok Bot, ChatGPT, Claude, or any MCP client.

We only store this name and the locations you post. No email, no phone, no account.

Hosted free by Tyler Jewell. Bare minimum. No data is kept. Everything in a group — names, positions, invites, and stats — is deleted automatically 24 hours after the group is created. Cap of 10 people. This project is not affiliated with Winter Park Resort or any other ski area. Map data © OpenStreetMap contributors. Read the privacy note and terms.
